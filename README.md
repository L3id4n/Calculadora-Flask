# Calculadora Flask
Uma calculadora web feita com Flask.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Potenciação
  
## Requisitos

- Python 3.14.3
- Flask
  
## Instalação

Clone o repositório:

git clone https://github.com/L3id4n/Calculadora-Flask

Entre na pasta:

cd calculadora-flask

instale as dependências:

pip install flask

## Como executar

python app.py

Depois abra:

http://127.0.0.1:5000
